# 课表编译 · 教务课表 Excel → ICS

把教务系统导出的课表 `.xls` 转成标准日历文件 `.ics`。全部解析在浏览器本地完成，不上传、不联网、不依赖后端。

## 用起来

1. 打开 `index.html`（或 Pages 地址）
2. 拖入课表文件，填第 1 周的周一
3. 点「下载 .ics」或「添加到日历」

## 做了什么

- 解析强智科技教务导出的课表表格：`★课程名/(学号)课程代码/教师/【周次】,地点`
- 同一格里多条记录按周次拆开，周次互补不会互相覆盖
- 连堂合并：同课程、同教师、同地点、节次连续，且相邻两节间隔 ≤5 分钟才合并；30 分钟大课间（10:05–10:35、15:35–16:05）自动断开
- 输出带 `VTIMEZONE Asia/Shanghai`、稳定 UID（重导同一门课会覆盖旧事件）、可选课前提醒
- 表底「备注」里的公选/实践课会单独列出，并按连续周次写成横跨的全天日程，不写入具体课时
- 页面里还有：周视图网格、自检报告、单周 PNG 导出、添加到系统日历（按平台分流）

## 已知限制

- 只识别上述表格版式，其他教务系统导出的表可能解析失败
- 调课、调休、节假日不会自动处理，需要手动在日历里改
- 合并模式用 `RRULE` 展开整周，遇到整周停课要手动删那一条

## 许可

仅供学习和个人使用。
